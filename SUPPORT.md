# Support

For installation, platform prerequisites, usage, diagnostics, and development
commands, start with the [README](README.md).

For help using brp or diagnosing a non-security problem, open a [GitHub
issue](https://github.com/gtkacz/brp_sharing/issues/new/choose) with the
relevant platform, brp version or commit, and redacted logs. Please do not post
room tickets, identity keys, private session content, or unredacted crash dumps.

For suspected vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of
opening a public issue.
