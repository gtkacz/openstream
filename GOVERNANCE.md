# Project Governance

brp is maintained by its project maintainers. Maintainers guide technical
direction, review contributions, manage releases, and enforce the project's
[Code of Conduct](CODE_OF_CONDUCT.md).

Changes are normally made through pull requests. Maintainers seek consensus for
material design decisions, particularly changes to the wire protocol, security
model, supported platforms, and public user experience. When consensus is not
reached, the maintainers make the final decision and document significant
trade-offs in the relevant issue or pull request.

Anyone may propose a change, report a problem, review a pull request, or
contribute documentation and tests. Sustained, constructive contributions may
lead to an invitation to help maintain the project.
